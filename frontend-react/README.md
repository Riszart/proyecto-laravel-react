# Distribuidora Nova — Catálogo

Aplicación web para consultar el catálogo de productos y categorías de Distribuidora Nova.

## Tecnologías

- React 19
- React Router
- Vite

## Desarrollo

```bash
npm install
npm run dev
```

La aplicación consume la API en `http://127.0.0.1:8000` (`/api/productos` y `/api/categorias`), por lo que el backend debe estar en ejecución.

## Scripts

- `npm run dev` — servidor de desarrollo
- `npm run build` — compilación para producción
- `npm run preview` — previsualizar el build
- `npm run lint` — verificación de ESLint
